W&B env vars are set but no logging code exists.

## Key Insight: Filename Divergence = Shadow System

The natural naming divergence between `0a_`/`0b_` (new canonical) and `0x_`/`9x_` (older/experimental) IS the shadow system. Per `docs/03-CANONICAL-FAERIE-FORMULAS.md` §Anti-Bloat Guardrail:

> 1. Measure baseline → 2. Propose formula → 3. Run shadow mode (5 sessions) → 4. Cutover when: shadow agreement >80% AND catches ≥1 decision baseline missed AND no harm

**Rule**: `0a_`–`0g_` prefix = canonical (production). `0x_`/`9x_` prefix = ghost (experimental/shadow). Ghosts get promoted to canonical by filename change only after RAP evidence.
