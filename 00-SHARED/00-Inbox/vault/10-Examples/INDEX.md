## What These Show

These examples show the complete session arc:
- `/faerie` orientation
- Wave planning and agent selection
- Manifest reading (what main actually sees)
- Queue effects (how next_task_queued chains tasks)
- `/handoff` memory promotion

The goal is to make abstract concepts concrete. After reading these,
the architecture docs should feel like they describe something you
have already seen in operation.
