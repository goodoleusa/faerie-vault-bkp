# 🔐 Forensic Governance Architecture

**Breadcrumb:** [[00-DASHBOARD]] > [[01-forensic-governance]]

> Maintain chain-of-custody (COC) integrity for faerie2 system artifacts, ensuring cryptographic auditability and real-time backup of critical metadata.

---

## Write Permission Model

### Allowed Writes (Agent + Claude)
- ✅ `forensics/manifests/` — agent outcomes, compass edges, discoveries
- ✅ `forensics/artifacts/` — work products (reports, code, analysis)
- ✅ `forensics/bundles/` — pre-rendered task context

### Denied Writes (Script-Only)
- ❌ `forensics/coc-entries/` — chain-of-custody audit trail (script writes only via signing)
- ❌ `forensics/*.jsonl` — COC logs (immutable, script-signed)
- ❌ `forensics/*-index*` — forensic indexes (auto-generated by scripts)
- ❌ `forensics/*-hash*` — hash chains (computed, not manually written)
- ❌ `forensics/*-chain*` — ledgers (appended via signed entries only)

---

## Workflow: Write → Sign → Hash → Backup

```
Agent completes work
  ↓
Write manifest to forensics/manifests/[YYYY-MM-DD]/[HH-MM-SS]_manifest_*.json
  ↓
[PreToolUse hook: 8x_state_write_coc_enforcer.py]
  Validates: manifest location allowed? COC files untouched? ✓
  ↓
[PostToolUse hook: 9x_forensic_signer.py]
  Signs manifest with agent Ed25519 key
  Creates COC entry in forensics/coc-entries/[YYYY-MM-DD]/
  Appends to forensics/manifest-chain.jsonl (hash-chained)
  ↓
[PostToolUse hook: 5x_b2_manifest_uploader.py --realtime]
  ⚡ REAL-TIME backup to B2 WORM bucket
  Critical metadata: manifest, COC entry, chain hash
  No waiting for session end — uploaded immediately
```

---

## Hook Enforcement Points

| Hook | Matcher | Purpose |
|------|---------|---------|
| **PreToolUse** | Write | Block writes to COC-protected files |
| **PostToolUse** | Write | Capture tool call, sign manifest |
| **PostToolUse** | Write(/forensics/manifests/**) | Real-time B2 upload |
| **SubagentStop** | — | Capture final agent state |

See [[02-settings-sync-strategy]] for hook configuration details.

## Recovery & Verification

```bash
# Verify manifest integrity (was it signed?)
python3 scripts/6x_forensic_recovery.py verify task-123

# Recover task artifacts (full chain from B2)
python3 scripts/6x_forensic_recovery.py recover task-123

# Audit COC chain (no breaks?)
python3 scripts/6x_forensic_recovery.py audit-chain task-123
```
