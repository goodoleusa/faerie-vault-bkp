# Living Formulas: From Measurement to Constraint

> *Opening summary: Describes the evolution of the faerie system from using manually-checked wave gates (W1/W2/W3) to formula-driven pacing where the math itself enforces spawn cadence and context budget. The "living" part: formulas are updated by the system as new data arrives (spawn counts, completion rates, context fill) so constraints evolve with system behavior rather than being static thresholds. This is the formal underpinning for the rocket-physics metaphor in CLAUDE.md.*
