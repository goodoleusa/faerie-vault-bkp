## Primary Research Papers

### [80-AUTONOMY-SYCOPHANCY-FRAMEWORK.md](80-AUTONOMY-SYCOPHANCY-FRAMEWORK.md)
**Status:** Publication-draft  
**Topic:** Measuring true agent autonomy vs sycophancy in transient agent systems  

Core contributions:
- **Five measurable autonomy signals:** refusal rate, articulated reasoning, decision drift, mission innovation, confidence-as-veto
- **Composite Autonomy Index (CADI):** numerical health metric for agent choice quality (target ≥0.72)
- **Ephemeral agent culture problem:** how agents that exist only hours contribute to persistent swarm culture through bundle chaining
- **NECTAR/HONEY contract:** explicit mechanism for knowledge persistence across sessions
- **Manifest evidence of choice:** schema for recording agent reasoning and decision-making

**Key insight:** Autonomy is not a philosophical luxury—it is the substrate of culture persistence in ephemeral systems.
